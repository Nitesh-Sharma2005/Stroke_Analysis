# 🏥 Stroke Risk Healthcare Dashboard (Excel)

## 🔍 Overview
This project presents an interactive healthcare dashboard built in Microsoft Excel to analyze stroke risk based on patient demographics, medical conditions, and lifestyle factors. The dashboard helps identify high-risk groups and key contributing factors to stroke occurrence.

---

## 🎯 Objectives
- Analyze stroke risk across different patient segments  
- Identify high-risk groups based on age, gender, and medical conditions  
- Evaluate the impact of lifestyle factors like smoking, diet, and alcohol  
- Provide an interactive dashboard for data-driven healthcare insights  

---

## 🛠️ Tools & Techniques Used
- Microsoft Excel  
  - Pivot Tables  
  - Pivot Charts  
  - Slicers (interactive filters)  
  - Data Cleaning  
  - Conditional Formatting  

---

## 📊 Dataset Columns
- Patient ID  
- Age  
- Gender  
- Region  
- Hypertension  
- Heart Disease  
- Smoking Status  
- Alcohol Consumption  
- Diet Type  
- Residence Type  
- Stroke Occurrence  
- Risk Score  

---

## 📈 Key Insights
- Patients with hypertension and heart disease show higher stroke risk scores  
- Smoking and alcohol consumption contribute significantly to increased risk  
- Certain regions (e.g., North) report higher stroke cases  
- Younger age groups (<30) show lower risk compared to older groups  
- Lifestyle and medical conditions combined have a strong impact on stroke occurrence

## 🚀 How to Use
1. Download the Excel file  
2. Open in Microsoft Excel  
3. Use slicers to filter by age group, region, lifestyle, and medical conditions  
4. Explore charts to analyze stroke risk patterns
